Este repositorio contiene 5 programas desarrollados en Python que utilizan estructuras condicionales (`if`, `elif`, `else`) para resolver diferentes problemas lógicos.

## Descripción de los programas:

1. **Clasificación de triángulos (`clasificacion_triangulos.py`)**
   Solicita al usuario las 3 longitudes de los lados de un triángulo y determina si es un triángulo equilátero, isósceles o escaleno.

2. **Año bisiesto (`anio_bisiesto.py`)**
   Pide al usuario que ingrese un año y evalúa si dicho año es bisiesto o no, utilizando las reglas de divisibilidad correspondientes.

3. **Conversor de calificaciones (`conversor_calificaciones.py`)**
   Toma una calificación numérica (del 0 al 100) e imprime su equivalencia en letra (A, B, C, D o F) según rangos predefinidos.

4. **Comparación de tres números (`comparacion_numeros.py`)**
   Solicita el ingreso de tres números y compara los valores para mostrar cuál de ellos es el mayor y cuál es el menor.

5. **Tarifa de entrada (`tarifa_entrada.py`)**
   Pide la edad de una persona para calcular y mostrar el costo de entrada a un parque de acuerdo a tres categorías: menores de 12 años, de 12 a 17 años, y adultos.
